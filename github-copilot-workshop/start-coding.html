Project Setup

15 minutes

You can use your own repository or work with the sample repository available at:

Project URL: https://github.com/Customer-Workshops/sample-repo-workshop.git

Step 1: Fork the Repository

First, open the project URL above in your browser and fork the repository:

  1. Open the project URL in your browser
  2. Click the Fork button in the top right
  1. Click the Create fork button on the fork creation screen. Once the fork is complete, a copy of the repository will be created in your GitHub account.

Step 2: Development Environment Setup

Using your forked repository, you can start the project using VS Code:

Clone to Local Environment

If you have VSCode installed locally:

  1. Open Terminal or Command Prompt
  2. Clone your forked repository with the following command:
git clone https://github.com/<your-username>/sample-repo-workshop.git
  1. Navigate to the cloned directory:
cd sample-repo-workshop
  1. Open the project in VSCode

Step 3: Workspace Setup

After opening the project, please install the following extensions (if you haven't):

  1. Install GitHub Copilot extension
  2. Login to GitHub Copilot using your GitHub account
Step 2 of 7

Code Completion

10 minutes

GitHub Copilot provides intelligent code suggestions as you type. Let's explore how to use this feature effectively.

Create a new JavaScript file named factorial.js in your project.

How Code Completion Works

As you write code, Copilot analyzes the context of your file and suggests completions. These suggestions appear as gray "ghost text" that you can accept with the Tab key.

Example Comment

Add a New Function Using a Comment

: Start typing a comment describing what you want: 
Write a function to calculate the factorial of a number.

Copilot will automatically suggest the full function implementation as ghost text.

Add a New Class Using a Comment

: Begin describing a class structure: 
Create a class named Invoice with amount, tax, and a method to calculate total.

Copilot will generate the class definition and related methods.

Generate Helper Methods

Add a utility function to format a date as DD-MM-YYYY.

Copilot will propose a ready-to-use helper function.

Complete Incomplete Code

function addUser(user) {
              // validate user inputs

Copilot will expand the validation logic and complete the rest of the function.

Add Comments or Documentation

Explain what this function does and list its parameters

Copilot will auto-generate a documentation block.

Note

If you don't see suggestions, make sure you're signed in to your GitHub account and have an active Copilot subscription.

Step 3 of 7

Copilot Chat

15 minutes

Copilot Chat is an interactive AI assistant that helps you understand code, generate functions, and get coding guidance through natural language conversations.

Opening Copilot Chat

  1. Click the Chat icon (chat bubble) in the VSCode sidebar
  2. Or open the Chat panel with Ctrl+Alt+I (macOS: Ctrl+Cmd+I)

Key Features

1. Explain Code

Option 1: Select code and ask Copilot to explain it:

Please explain this entire file.

Option 2: Select code and ask Copilot to explain it using slash commands:

/explain

Model to use for this exercise: GPT-5 mini

2. Generate Functions

Ask Copilot to write code for you:

Create a function that validates an email address and returns true if valid.

Model to use for this exercise: MAI-Code-1.1-Flash

3. Translate to New Technology

Convert code from one language or framework to another:

Convert this JavaScript function to Python.

Model to use for this exercise: Kimi K2.7 Code

4. Code Improvement

Get suggestions to improve your code quality:

How can I improve the performance of this function?

Model to use for this exercise: GPT-5 mini

Tip

Use the # symbol to reference files in your prompts, like #app.py to give Copilot context about specific files.

Step 4 of 7

Plan Mode

10 minutes

Plan Mode helps you create a structured development plan before implementation, without spending AI credits writing code you might throw away. This is part of Spec-Driven Development, a recommended approach for AI-assisted coding.

Example: Plan a Pong Game on an Ultra-Low Credit Budget

Select Plan mode in Copilot Chat, then copy and paste the prompt below as-is. It asks Copilot to design a complete plan for a simple Pong game while staying within a strict 25-50 AI credit budget — a great way to see how far a small budget can go.

Act as an expert software architect specializing in ultra-low budget AI code generation. I have a strict limit of 25-50 AI credits to build a complete browser game.

Do not write any game code yet. Instead, generate a comprehensive, single-turn development plan for a simple Pong game.

Your plan must include:

1. Architectural Layout: How to combine HTML5, CSS, and Vanilla JavaScript into a single, lightweight file.
2. Asset Alternatives: Detailed description of how to use pure CSS and HTML Canvas drawing to avoid external images or sound files.
3. State Management: A simple layout of the game loop, win/loss conditions, and score tracking variables.
4. Token Optimization: Strategies to keep the final code generation request highly condensed to fit within minimal credit usage.
Tip

Review the generated plan before building anything. If a step looks like it will burn too many credits, ask Copilot to simplify it before moving on.

Saving the Plan

Switch to Agent mode and save the plan so it can guide implementation in the next step:

Save the development plan in a file called plan.md
Step 5 of 7

Agent Mode

15 minutes

Agent Mode is Copilot's most autonomous feature. It can execute multi-step tasks, run commands, and make complex changes across your project. Below are two small, low-cost use cases you can try — copy and paste each prompt directly.

Enabling Agent Mode

  1. Open Copilot Chat
  2. Select Agent from the mode selector at the bottom of the chat panel

Use Case 1: Build the App from the Plan

Using the plan.md file you saved in the previous step, ask Agent Mode to implement it:

Using the plan.md file we created, implement the Pong game exactly as specified. Keep the implementation in a single HTML file and keep the code generation condensed to conserve AI credits.

Use Case 2: Add a Dark/Light Theme Toggle

Small, self-contained features are a great way to try Agent Mode without spending a lot of credits:

Add a dark/light theme toggle button to the game. Use plain CSS variables and vanilla JavaScript only, no new dependencies. Keep the change small and focused on the toggle button and theme variables.
Caution

Agent Mode can run commands and modify files. Always review the actions it proposes before allowing them to execute.

Step 6 of 7

Add Unit Tests

15 minutes

Let's use Copilot to add comprehensive unit tests to our application.

Generate Unit Tests

Use the following prompt to have Copilot create unit tests:

We want to add unit testing to this project.
Please create 2-3 unit tests for the most important function(s) in this application.
Install necessary libraries to support this change.
Then in the readme file, add explanation on how to run the unit tests.

Running Tests

You can ask Copilot to run the tests directly from the Chat panel:

Run the unit tests and show me the results.
Tip

Copilot can automatically check test results and make adjustments if tests fail. It uses your custom instructions and architecture document to ensure consistency.
